Features
--------

* **Gaussian Mixture Model Thresholding**: Automatically identify cell cycle phases using GMM-based methods
* **Sequential Thresholding**: Apply thresholding sequentially across multiple features
* **Visualization Tools**: Built-in plotting functions for quality control and results
* **AnnData Integration**: Works seamlessly with scanpy/AnnData workflows
